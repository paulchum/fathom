# Feedback and proposed changes

Thanks for helping make the workbench clearer and more useful.

For a numerical issue, include the model version, exact inputs, expected output and an independent calculation or primary reference. For an interface issue, include your browser, viewport/device and steps to reproduce. Share only non-confidential scenarios.

Before a larger change, open an issue describing the user problem and proposed scope. Avoid uploading source datasets, business records or materials without the necessary permissions.

Use Node.js 22+ and run `npm run check`. No dependency installation is needed. Keep numerical functions pure, validation centralized, units explicit and exports backward compatible. An incompatible equation/schema change needs a new model version. Include a meaningful independent reference or invariant test when changing model behaviour.

Changes to the interface should work with keyboard input, narrow screens and reduced-motion preferences. Preserve the distinction between heat-transfer flow and water consumption, and between an illustrative estimate and an engineered design.

The repository is intentionally unlicensed for now. Do not assume an open-source licence or add third-party material under incompatible or unclear terms. A future licensing decision is reserved to the project owner.
