# Provenance and publication boundary

FATHOM's earlier work explored marine compute infrastructure, regional spatial evidence and local diligence workflows. This browser workbench implements a smaller general-purpose subset of the modelling ideas: energy accounting, scenario comparison and liquid-loop heat transport.

## This repository

- New JavaScript model, interface, original vector diagrams, CSS and documentation created for the public workbench.
- General physical relationships are documented in [METHODOLOGY.md](METHODOLOGY.md) with primary references.
- Reference inputs are illustrative, editable assumptions. No named vendor, site, deployment or approved operating point is represented.
- No runtime third-party packages, external font services, map tiles or private datasets are required.

The work was informed by the FATHOM software-only engineering evidence package v0.1.0 (August 14, 2026) and the local diligence-workspace handoff (September 7, 2026). The earlier thermal model is substantially broader: it includes coupled losses, heat-exchanger limits and other constraints. This public workbench does not claim equivalence to that model or reproduce its performance conclusions.

## Excluded

The publication does not include regional GIS datasets, application/rights packages, contact lists, investor materials, private business plans, raw research archives, local paths or runtime records. Those assets have separate evidence, privacy and licence considerations.
